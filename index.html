Transformações

Registre uma compra que rende mais de uma coisa depois de limpar/processar (ex: carne crua → carne limpa + gordura + descarte). O custo é rateado proporcionalmente ao peso útil, sem custo pro descarte. Uma transformação pode ser usada em vários preparos.

Exportar para Excel

Gera um arquivo .csv com todos os preços registrados e seus campos associados (item, categoria, data, local, comprou, quantidade de referência, observações). Abre normalmente no Excel / Google Sheets.

Formato de planilha, fácil de abrir e analisar no Excel. Não inclui as fotos.

Importar preços (.csv)

Restaura preços a partir de um .csv exportado por este app. Categorias e itens que não existirem serão criados automaticamente (sem foto). Preços já importados antes não são duplicados.

Backup completo (.json)

Guarda tudo que está no app: preços, itens, categorias, locais, receitas, preparos, transformações, unidades, configurações e fotos. Use para fazer uma cópia de segurança completa ou transferir os dados para outro celular.

Atenção: importar um backup .json substitui TODOS os dados atuais do app pelos dados do arquivo.

Sobre

Versão do app:

Este app funciona 100% offline. Os dados ficam salvos apenas neste aparelho, dentro do armazenamento do app instalado (Chrome). Se desinstalar o app ou limpar os dados do Chrome/do site, o histórico é perdido. Por isso, faça backups periódicos (.csv para preços, .json para tudo incluindo fotos).
